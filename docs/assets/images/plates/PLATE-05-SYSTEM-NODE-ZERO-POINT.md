## CSE Mapping

### The Atomic Unit
This is the most reduced possible representation of CSE's operational ontology. Every system node — from a single human participant to a planetary-scale infrastructure array — is composed of exactly two elements:

- **0 (iCU = 0):** The reservoir of potential, undocked, unrecorded capacity
- **1 (iCU = 1):** The active, engaged, recorded participant
- **System Node:** The emergent entity that exists ONLY when both are present and coupled

### Why Addition, Not Multiplication?
0 × 1 = 0. If either component is missing, the result is nothing. But 0 + 1 = 1 — the system node takes on the character of the active element while retaining the memory/context of the potential element.

This is crucial: the node does not forget its 0-state. Every iCU = 1 node carries the knowledge of what it was like to be iCU = 0. This is the empathy substrate of CSE — no node loses touch with the pre-engagement condition.

### 4C Stress Test
- **Conflict:** War destroys 1s (active nodes) but rarely destroys 0s (potential). The equation ensures recovery is possible as long as the 0-reservoir persists.
- **Climate:** Environmental degradation may shrink BOTH pools. When 0 → 0 (no potential remains), the equation produces no new nodes. Species extinction is 0-reservoir collapse.
- **Contagion:** Pandemic can temporarily convert 1s to 0s (isolation, death). The equation is reversible: System Node → 0 + 0 (degraded) or 0 + 1 (re-engaged after recovery).
- **Cost:** Maintaining the "+" operator (the coupling mechanism) has cost. If coupling becomes too expensive, 0s and 1s exist but do not form System Nodes. Infrastructure decay is uncoupling.

- **Recursion:** The equation applies at every scale. A family is a System Node. A city is a System Node. Civilisation is a System Node. Each obeys 0 + 1 = System Node.

## Signal Formula Integration

- **A:** Coupling amplitude — how strongly the 0 and 1 are bound into a System Node
- **P:** Persistence of both components (does the 0-reservoir renew? do 1s stay engaged?)
- **β:** Resistance to coupling (bureaucracy, access barriers, trust deficits, language gaps)
- **Result:** S is proportional to the density of System Nodes, not raw population.
