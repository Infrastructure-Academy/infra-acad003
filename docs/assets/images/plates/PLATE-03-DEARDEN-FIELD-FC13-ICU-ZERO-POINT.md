# Plate 03: Dearden Field FC13 = iCU = 0 (Zero Point)

## Visual Description
The Dearden Field at FC13 (Field Coordinate 13) mapped to iCU = 0. Labelled "Zero Point" — the origin state of the Civilisational Systems Engineering lattice before any human node docks.

## CSE Mapping

### iCU = 0: The Pre-Engagement Reservoir
This is the most critical concept in operational CSE. iCU = 0 does NOT mean "nothing." It means "everything that is potential but not yet recorded."

**Canonical phrase:**
> "Zero means nothing compared to 1 that means everything — yet zero makes the system work."

### Four-Layer Meaning at Zero Point
1. **Infrastructure Connection Unit (technical):** The docking gate is closed. No handshake. The system listens but does not log.
2. **Individual Cognition Unit (human):** The human exists but has not engaged the CSE framework. They are a signal, not a node.
3. **Intensive Care Unit (emergency):** The stabilisation layer is dormant. No patient (system) requires intervention.
4. **I See You / Eye See You (recognition):** Bidirectional gaze is not yet established. The machine does not see the human; the human does not see the machine as a partner.

### The Zero Point Function
- All undocked humans, unactivated infrastructure, and latent capacity exists in the iCU = 0 reservoir
- The health of CSE is measured NOT by how many iCU = 1 nodes exist, but by the system's capacity to convert iCU = 0 → iCU = 1
- A system with 1,000 iCU = 1 nodes and zero conversion capacity is DYING
- A system with 10 iCU = 1 nodes and massive iCU = 0 reservoir is ALIVE and GROWING

### 4C Stress Test
- **Conflict:** War kills iCU = 1 nodes but rarely touches the iCU = 0 reservoir (the unengaged population). Post-conflict recovery is possible if conversion capacity survives.
- **Climate:** Environmental collapse may reduce total population (shrinking iCU = 0 pool) while simultaneously increasing conversion motivation.
- **Contagion:** Pandemics can simultaneously reduce both pools. The 1,093-node saturation limit becomes relevant — if too many iCU = 0 signals attempt to dock simultaneously, the system jams.
- **Cost:** Maintaining iCU = 0 listening capacity has a cost. The system must spend resources on "empty" gates to be ready for future docking.

### 4R Recovery
- **Revelation:** Zero Point makes visible the invisible — all the people who *could* engage but haven't yet
- **Resilience:** The iCU = 0 reservoir is the system's shock absorber. Loss of active nodes can be rebuilt from this pool.
- **Regeneration:** Every new iCU = 1 node was previously iCU = 0. Regeneration is fundamentally a conversion operation.
- **Recursion:** The Zero Point concept applies recursively — within each node, there are sub-systems that have their own iCU = 0 / iCU = 1 states.

## Signal Formula Integration
S = A × P / β
- **A:** Amplitude of iCU = 0 → 1 conversion events per unit time
- **P:** Persistence of the iCU = 0 reservoir (does the population sustain itself?)
- **β:** Resistance factors that block conversion (education gaps, access barriers, trust deficits)
- **Result:** The Signal of a healthy CSE system is HIGH conversion rate, not high absolute node count
