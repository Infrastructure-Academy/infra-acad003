# iAAi Recovered Materials Archive

**Created:** 2026-08-23

This archive contains the iAAi project materials that were accessible in the connected Google Drive at the time of packaging. It is a preservation archive of recovered project files, not an official Manus Task Data Backup.

The archive does not contain a verified Manus website export, website database, Manus-hosted configuration, secrets, scheduled tasks, login data, or a deployed Cloudflare Worker. The authenticated Cloudflare account was checked during this task and contained no deployed Workers. The official Manus backup portal required account login and no completed export package was available in the accessible workspace.

The files are included without modification where downloaded. SHA-256 values for every included file are recorded in SHA256SUMS.txt.

For legal or evidentiary use, preserve this archive unchanged, retain the SHA-256 manifest, record the download source and time, and have qualified counsel or a records professional determine whether additional records are required.

## Included source locations

The included iAAi files were recovered from the connected Google Drive. Their original Drive file IDs, names, modification times, and web links are recorded in SOURCE_MANIFEST.csv.
