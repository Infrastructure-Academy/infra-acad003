# SEO and narration release rules

Only `READY` cards are included in `sitemap-bitpoints-ready.xml` and receive `index,follow`. Conditional and Hold cards are marked `noindex,nofollow` until corrected.

The narration queue intentionally contains no generated audio. Final audio should be produced only after copy approval, using a warm neural voice and the pronunciation profile already established for iAAi properties. Browser Web Speech must not be used as the final narration layer.
