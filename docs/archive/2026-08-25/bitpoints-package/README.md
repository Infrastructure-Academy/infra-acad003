# BitPoints Series 1 — Website/CDN Bundle

This bundle contains 60 original JPEG card images plus large, medium, and thumbnail WebP derivatives. Use `data/cards-ready.json` for production by default. `cards-conditional.json` requires the listed correction or crop; `cards-hold.json` must not be published as final.

The manifest preserves the 1792:2400 portrait aspect ratio. Display the full card with `object-fit: contain`; do not crop the title, body, or footer. All copy remains visible rather than hidden behind modal or accordion interfaces.

Each card has a `narration_text` field and an empty `narration_audio_url`. Generate final neural narration before wiring the provided `NarrateButton` contract. Browser Web Speech is not an acceptable final voice.

BitPoints are linked many-to-many to the canonical 143 InfraDex species and do not replace them. The integration manifest also provides the proposed DAVID role, iGO asset type, OEAT entry stage, and player action.


## Living-experiment use

For PoC and trial play, use `data/cards-living-experiment.json`. All 60 cards may be used as learning gifts. The experimental state determines how the card is framed and which Spider feedback invitation accompanies it; it is not a censorship or embarrassment label. Production-readiness manifests remain preserved as evidence.
