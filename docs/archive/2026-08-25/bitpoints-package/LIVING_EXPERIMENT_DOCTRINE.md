# BitPoints Living Experiment Doctrine

BitPoints cards are **surprises and gifts of learning** distributed through the iGO lattice. Series 1 is a trial and proof of concept, so perfection is not the admission test. The original proposition, every identified error, every player challenge, and every successful connection are retained as experimental evidence.

The evidence cycle is **Thesis → Antithesis → Synthesis**. The original asset is never silently overwritten. A revision creates a new version with its own checksum and a change-log entry linking the observation that caused it.

The former `READY / CONDITIONAL / HOLD` values are preserved as production-readiness evidence, but public trial use is reframed as:

| Experimental state | Player-facing badge | Use |
|---|---|---|
| `DISCOVERY_READY` | Learning Gift | Sprinkle freely through the lattice. |
| `OPEN_EXPERIMENT` | Living Experiment | Use with the current finding visible and invite feedback. |
| `THESIS_CASE` | Thesis Challenge | Present proposition and challenge together as a deliberate reasoning encounter. |

The Spider feedback panel is visible beneath every card. It asks for observation, evidence, and suggested synthesis without hiding the learning process behind a modal or accordion.
