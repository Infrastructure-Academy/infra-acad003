MASTERY PATHS

Four learning tracks through the Infrastructure Academy framework

THE OBSERVER

Entry level — Awareness

Read the Start Here guide. Watch the relay videos. Browse La Menara. Understand that infrastructure is not "things" but "relationships between things." Complete the iGO Observer Badge by visiting 3 relay pages and completing the Framework quiz.

THE STUDENT

Intermediate — Application

Work through Volume 1 (The Perspective) and Volume 2 (The Guide). Complete the 4-Pillar analysis for 3 relays. Use the ISI Calculator to analyse a real infrastructure project. Earn iCARDS through the iGO game and reach Tier 2 (Intermediate).

THE SCHOLAR

Advanced — Synthesis

Complete the full 12-relay analysis across all 5 Webs. Write a thesis applying the framework to a specific infrastructure domain. Use the DAVID Reality Engine for 3D spatial analysis. Reach Tier 3 (Advanced) in iGO with 50+ iCARDS collected.

THE ARCHITECT

Expert — Creation

Contribute original analysis to the framework. Create new La Menara entries. Build and share infrastructure case studies using the ISI Calculator. Mentor Observers and Students. Reach Tier 4 (Expert) in iGO and unlock the Architect Badge — the highest honour in the Academy.
