## PREFACE — How to Use This Book

This textbook is the companion volume to the CSE Teaching Deck series (Parts 1–4). It is written for students encountering Civilisational Systems Engineering for the first time — whether undergraduate engineers, postgraduate researchers, or self-directed learners.

The book follows a single pedagogical arc:

| Chapter Block | Function | Question Answered |
|---------------|----------|-------------------|
| Chapters 1–3 | Philosophy | *What is civilisation?* |
| Chapters 4–6 | History | *How does civilisation behave?* |
| Chapters 7–9 | Measurement | *How does civilisation perform?* |
| Chapters 10–12 | Engineering | *How can civilisation be improved?* |

Each chapter includes:
- **Definitions** (boxed, numbered, referenceable)
- **Worked Examples** (from the Golden Excel canonical database)
- **Plate References** (to the iAAi visual plate series)
- **Exercises** (progressive difficulty: recall → application → synthesis)
- **Key Equations** (numbered, with derivation notes)

**Prerequisite knowledge:** Basic algebra, familiarity with exponential functions, general awareness of world history. No specialist engineering background required.

#### CHAPTER 4 — The Forgetting Curve and the Remembrance Curve

**Core Thesis:** Ebbinghaus discovered the decay law. iAAi engineers the counter-law. The Remembrance Equation unifies micro-forgetting and macro-remembrance into a single civilisational architecture.

4.5 — Decay Term vs. Remembrance Term (structural comparison)
4.6 — From Individual Memory to Civilisational Memory (scale invariance)

**Key Equations:**

> **Equation 1 — The Forgetting Curve (Ebbinghaus):**
> R(t) = R₀·e^(-t/S₀)
> Where R₀ = baseline performance, S₀ = decay constant, t = time

> **Equation 2 — The Remembrance Curve (iAAi):**
> R(t) = 1 - e^(-n/N)
> Where n = number of revisits, N = spacing scale (target horizon)

> **Equation 3 — The Canonical Remembrance Equation:**
> R(t) = R₀·e^(-t/S₀) + k·(A×P/β)·(1-e^(-n/N))
> The forgetting curve is natural. The remembrance curve is engineered.
> iAAi transforms decay into consolidation through structured revisitation.

**Diagnostic Decision Tree:**

```
IF ISI < 0.30 (CRITICAL):
  → Primary: RECURSION (need more revisits before other levers work)
  → Secondary: REGENERATION (if β > 0.50)

IF 0.30 ≤ ISI < 0.60 (WARNING):
  → IF β > 0.45: REGENERATION (reduce resistance first)
  → IF β ≤ 0.45 AND n < 4: RECURSION (add revisits)
  → IF β ≤ 0.45 AND n ≥ 4: REVELATION (boost amplitude)

IF 0.60 ≤ ISI < 0.85 (GOOD):
  → IF A < 0.75: REVELATION (encoding is weak)
  → IF A ≥ 0.75 AND β > 0.35: REGENERATION (drag still high)
  → ELSE: RECURSION (push toward saturation)

IF ISI ≥ 0.85 (EXCELLENT):
  → SATURATED — maintain current parameters
```
