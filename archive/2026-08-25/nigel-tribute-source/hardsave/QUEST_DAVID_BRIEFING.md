### The Signal Formula
S = (A × P) / β

Players must maximize their signal (infrastructure impact) by:
- **A (Amplitude):** Reach — how many people does this infrastructure serve?
- **P (Persistence):** Duration — how many centuries will it last?
- **β (Resistance):** The 4Cs that threaten infrastructure:
  - **Conflict** (war, destruction of records)
  - **Climate** (flood, fire, erosion)
  - **Contagion** (plague, societal collapse)
  - **Cost** (economic failure, depletion)

**Game Mechanic:** Players build infrastructure networks and must defend them against random 4C events. High amplitude + long persistence = high signal. Low resistance = infrastructure survives.

**The Core Principle:** "Maximise the numerator. Minimise the denominator. That is the entire game."

## JUNE 2026 INCIDENT ANALYSIS

**What Happened:** The Infrastructure Academy website showed old content despite correct DNS settings. 15,000 tokens were wasted debugging the wrong issue.

**Root Cause:** Stale files in the /docs folder of the infra-acad003 repository. The DNS was correct, but the actual files being served were outdated.

**Lesson for You:** When deploying game updates or data changes, verify that the actual files are updated, not just the configuration. Test the live endpoint, not just your local build.

**Verification Commands You Should Know:**
```bash
# Check file size and timestamp
ls -lh /path/to/your/game/files

# Verify content is live
curl -s https://your-game-endpoint.com | grep 'expected-content'

# Check git status
git log --oneline -5
```
