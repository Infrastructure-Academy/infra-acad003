# Memorial Browser-Rendered Route Captures

Snapshot date: 2026-08-25

Base URL: https://nigelmemorial-ucmtq9dn.manus.space

This directory contains the markdown captures produced by browser-rendered visits to all 31 public Memorial content routes listed in `../memorial-route-list.txt`. The files preserve the rendered text and links available to the browser session at capture time.

The captures are an evidence and text-preservation layer. They are not a complete offline reconstruction of the React application: external CDN images, videos, downloads, interactive state, database rows, authentication state, and server-side behavior remain external unless separately archived.

The capture filenames are derived from the live route URLs. The route-by-route status, page title, and capture references are recorded in `../memorial-browser-capture-log.md`.

The source project snapshot is preserved separately under `../nigel-tribute-source/`. This archive contains no `.env` files, credentials, or live database rows.
